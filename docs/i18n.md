# Languages

The app ships in **English** (`en`) and **Hindi** (`hi`). Every string on screen, in voice prompts and in the printed report comes from `src/i18n/locales/<code>.json`.

## Add a language (e.g. Kannada) — no code changes

1. Copy `src/i18n/locales/en.json` to `src/i18n/locales/kn.json`.
2. Fill in `_meta`:
   ```json
   "_meta": { "name": "ಕನ್ನಡ", "locale": "kn-IN", "speech": "kn-IN" }
   ```
   - `name`: shown in Settings → Language, written in the language itself.
   - `locale`: used for dates ("ಶುಕ್ರವಾರ, 20 ನವೆಂಬರ್") and plural rules.
   - `speech`: voice for prompts. If the phone has no voice for it, the browser falls back to its default.
3. Translate every value. Keep the `{placeholders}` exactly as they are, and keep plural groups (`"one"` / `"other"`).
4. Run the tests:
   ```bash
   npm test
   ```
   The locale tests fail if a key is missing or extra, a placeholder differs, a string is empty, or wording claims diagnosis, treatment or cure.

The new language appears in Settings automatically (files are picked up with `import.meta.glob`).

## Wording rules

- Use "exercise tracking", "supports", "session", "comfort".
- Never claim diagnosis, treatment, therapy outcomes or cure (tests check English and Hindi for this).
- Keep the safety notice: "Not a medical device. Prototype. Use under supervision."

## Fonts

No web fonts are bundled (the app is served from the ESP32 flash). Devanagari and Kannada render with the phone's system fonts (Noto Sans on Android, Nirmala UI on Windows).
